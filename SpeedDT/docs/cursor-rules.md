# Cursor Rules

Before generating code, always read:

- docs/frontend-spec.md

Rules:

1. Use Expo-compatible packages only.
2. Use TypeScript.
3. Use NativeWind.
4. Prefer reusable components.
5. Follow existing folder structure.
6. Use mock data.
7. Do not create backend code.
8. Do not create authentication.
9. Do not create SQLite logic.
10. Do not create GPS logic.
11. Do not create notification logic.
12. Keep files small and maintainable.
13. Match provided UI mockups closely.
14. Avoid unnecessary complexity.
15. Use functional React components.
